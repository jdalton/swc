SWC frame comparison:
Build cargo build -p swc_native_addon --release --example compare_decoding in the SWC repository at 2ccb29d1a290658d58d35536f945f991324df93c (streaming decoder unchanged through the baseline 3d54a0896). Included compare_decoding.rs is that source. Run python3 frame-run.py <built-compare_decoding> <swc.node>, then python3 frame-analyze.py. It reads .search8.zst and .memory21.zst beside the input. Five alternating process pairs, 14 rounds/process, first 2 warmups excluded. Each timed region includes streaming decode with full runtime BLAKE3 into a fresh tempfile; no fsync. Independent SHA-512 verification is outside timing. Rspack does not need a frame comparison because its encoded frame is identical.
